LEARNING OBJECTIVE
Understand how adjusting the intercept and slope of a linear model alters its fit to a
dataset. Visualize how these parameter changes map to movements on a two-dimensional
loss surface, where the goal is to find the global minimum.
SCENE PLAN
1. Hook — Every machine learning model must find the best parameters to fit its training
data. We can visualize this search by mapping how changes in a model's intercept and
slope affect its overall error on a two-dimensional loss surface.
2. Construction — Build a split-screen visualization with a data scatter panel on the
left and a 2D contour plot of the loss surface L[phi] on the right. Populate the left
panel with 28 data points and an initial fitted line, while placing a marker on the
right panel at the corresponding initial parameter coordinates for intercept phi_0 and
slope phi_1.
3. Demonstration — Drag the current parameter location on the 2D loss surface L[phi] to
simultaneously update the fitted line in the data scatter panel, showing intercept phi_0
and slope phi_1 changing together. As the marker moves toward the global minimum of the
contour plot, the loss decreases, and the line aligns with the data distribution,
demonstrating how both parameters jointly determine the model's accuracy.
4. Demonstration — Drag a slider for the intercept phi_0 from -1 to 2 to shift the
fitted line up and down in the data panel while the marker moves vertically on the loss
surface. Increasing the intercept translates the line higher along the y-axis without
changing its angle, causing the loss value to rise and fall as the marker crosses
different error contours on the vertical axis.
5. Demonstration — Drag a slider for the slope phi_1 from 0 to 4 to rotate the fitted
line in the data panel while the marker moves horizontally on the loss surface.
Increasing the slope steepens the angle of the line, which sweeps through the data
points and drives the marker horizontally across the loss landscape, highlighting how
the error changes with respect to the slope alone.
6. Consolidation — By independently and jointly varying the intercept and slope, we see
exactly how parameter updates alter the model's predictions. This dual view confirms
that minimizing the loss function on the landscape directly corresponds to finding the
optimal line of best fit for the training data.
CONSTRAINTS
- Render in 2D unless the figure is inherently 3D. Keep every axis, label and symbol

- Name the physical quantities and their units; keep the geometry quantitatively honest.
- Each demonstration must actually play out on screen: sweep the parameter through its
range and show the figure responding.
- Narration must be synchronised to the visual it describes.
